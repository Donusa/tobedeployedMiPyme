¿Qué información guardamos?

A continuación encontrás cada categoría de datos que el sistema almacena, con una descripción detallada de cada campo.

Perfil de usuario

Cuenta
  • Nombre completo
  • Dirección de email
  • Rol en el sistema
  • Permisos asignados

Empresa / Tenant

Organización
  • Razón social y nombre comercial
  • CUIT / identificación fiscal
  • País, provincia y ciudad
  • Rubro / industria
  • Email y teléfono de contacto
  • Domicilio fiscal
  • Código SSO de tenant

Sesiones activas

Seguridad
  • Identificador de sesión
  • Información de dispositivo
  • Dirección IP de origen
  • Fecha de inicio de sesión
  • Última actividad registrada

Historial de accesos

Seguridad
  • Fecha y hora de cada acceso
  • Dirección IP
  • Dispositivo / navegador
  • Resultado del intento (exitoso / fallido)

Notificaciones

Actividad
  • Tipo de notificación
  • Contenido / mensaje
  • Estado de lectura
  • Fecha de creación

Preferencias locales

Configuración
  • Tema visual (claro / oscuro)
  • Idioma seleccionado
  • Recordar sesión

Guardadas en tu navegador (localStorage), no en nuestros servidores.

Tu privacidad es nuestra prioridad. MiPyme almacena únicamente los datos necesarios para el funcionamiento del servicio. No vendemos ni compartimos tu información personal con terceros. El archivo exportado es de uso personal y puede contener datos sensibles; guardalo en un lugar seguro.
